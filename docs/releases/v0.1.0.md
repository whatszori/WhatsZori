# WhatsZori 0.1.0

The first public version: a desktop WhatsApp client that keeps what others delete, lets you read without being seen, and looks the way you want.

> **Early version.** It hasn't been through much testing with real accounts yet. WhatsApp's terms don't allow third-party clients, so if you can, try it with a second number first. WhatsZori can't send in bulk or auto-reply, and it rate-limits what you send, but the risk isn't zero.

The Windows build isn't signed, so SmartScreen may warn the first time: choose **More info → Run anyway**.

On Linux, install the libraries first (`sudo apt install libgtk-4-1 libwebkitgtk-6.0-4` on Ubuntu 24.04, `sudo pacman -S gtk4 webkitgtk-6.0` on Arch), unpack the archive and run `./WhatsZori`. The Linux build has had less testing than the Windows one.

## What's in it

**Nothing disappears**
- Messages deleted for everyone stay, marked with who deleted them and when
- Every earlier version of an edited message
- A *Deleted & edited* screen across all chats
- View-once photos and videos kept and saveable
- Statuses kept, deleted ones too

**Ghost mode**
- Hide online and typing
- Read receipts: always, never, or only when you reply
- Hide "played" on voice notes
- Full ghost mode for chosen chats
- View statuses without appearing in the viewer list

**Everyday**
- Chats and groups, replies, reactions, edits, delete for everyone and for me
- Photos, videos, video notes, GIFs, documents, stickers
- Voice notes: record and send, with a waveform
- Search across chats and inside a chat
- Polls with results and voting
- Forwarding to up to five chats, multi-select
- A full emoji picker, your own stickers
- New chat from contacts or by number
- Contact and group info, favourites and chat lists, export to HTML, TXT or JSON
- Notifications with reply, tray icon with an unread badge, close to tray

**Make it yours**
- Themes: CSS files and theme folders, with Adwaita, WinUI and Classic Green built in
- Your own chat wallpaper
- Plugins from the config folder, with the [plugin SDK](https://github.com/whatszori/plugin-sdk)

## Getting started

1. Run `WhatsZori.exe`.
2. On your phone: **WhatsApp → Settings → Linked devices → Link a device**, and scan the QR code. Or choose *Link with phone number instead*.
3. Your recent chats come over.

The [guide](https://whatszori.obzori.dev/guide/) covers the rest. Your data stays in `%AppData%\whatszori`. There's no server, account or analytics.

## Known limits

- No calls.
- The two grey ticks ("delivered") can't be hidden.
- WhatsApp often sends view-once media only to the phone; then WhatsZori can't open it.
- Poll creation isn't there yet, only voting.
- The interface is English only.

## По-русски

Первая публичная версия WhatsZori: клиент WhatsApp для компьютера, который сохраняет удалённые сообщения, позволяет читать незаметно и выглядит так, как вам нравится.

Это ранняя версия: на настоящих аккаунтах её проверяли мало, а правила WhatsApp запрещают сторонние клиенты. Если есть возможность, попробуйте сначала со вторым номером.

Скачайте `WhatsZori-0.1.0-windows-x64.exe` и запустите. Если Windows предупредит, нажмите **Подробнее → Выполнить в любом случае**. Затем на телефоне откройте **Настройки → Связанные устройства → Привязка устройства** и отсканируйте QR-код. Подробности — в [руководстве](https://whatszori.obzori.dev/ru/guide/).
